# Cars Dealership - Full Stack Capstone Project

**Repository name:** xrwvm-fullstack_developer_capstone
**Project name:** Cars Dealership

A full-stack web application for a national car retailer where users can view dealerships, read reviews and submit reviews.

## Tech Stack
- Frontend: React
- Backend: Django, Node.js/Express, MongoDB, SQLite
- Deployment: Docker, Kubernetes, IBM Cloud Code Engine
- CI/CD: GitHub Actions
